# Premium sayfasi gorsel asset'leri

Bu klasore `hero.webp` konuldugunda premium sayfasinin ust bandinda (hero)
otomatik gosterilir. Dosya yoksa kod, tac amblemi CSS fallback'i gosterir
(kirilmaz, bos gozukmez).

Avantajlar artik **AI gorseliyle degil**, canli profil kanvasiyla (Premiumsuz <-> Premium
gecisi) gosteriliyor — yani perk-*.webp gibi ayri illustrasyonlara gerek yok.
