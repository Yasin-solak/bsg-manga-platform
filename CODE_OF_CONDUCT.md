# Code of Conduct

This project is a place for people who enjoy building software and reading manga. Everyone should be able to take part without harassment, whatever their background or experience.

## Expected behavior

- Be respectful and assume good intent.
- Give and accept critique about the work, not the person.
- Help newcomers.

## Unacceptable behavior

- Harassment, insults, or discriminatory language
- Personal attacks or publishing someone's private information
- Sexual content involving minors in any form
- Requests for help publishing pirated content

## Enforcement

Report problems privately to the project owner through GitHub. Maintainers may edit or remove contributions and may block people who break these rules.
